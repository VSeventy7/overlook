# V3 — Couch TV

V3 is the default on supported Android versions. It includes the upstream Couch TV on-TV interface and backend, with Overlook’s version switch, Refresh, original wallpaper/folder/settings controls and PatchWall shortcuts. Choose v2 or v1 from the top-right version menu at any time.

Use `options=version=v3` in the generic home configuration. Your app data and signing identity remain the same. Android 9 on the Mi TV is validated; other Android firmware needs separate verification. Devices below API23 retain the native versions.

See [setup, controls, architecture and limitations](../../../../docs/v3-couch-tv.md).
